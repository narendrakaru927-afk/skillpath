# SkillPath - Six Skills Version

A beginner-friendly career suggestion website made with HTML, CSS, and JavaScript.

## Skills included
- HTML
- CSS
- Java
- Python
- SQL
- Git

## How to run
1. Open this folder in Visual Studio Code.
2. Open `index.html`.
3. If you have the Live Server extension, right-click `index.html` and choose **Open with Live Server**.
4. Select one or more skills and click **Find My Career Paths**.

## How it works
The website compares selected skills with sample career skill lists written in `js/script.js`. It calculates a simple overlap percentage and suggests skills to learn next.

This is a student prototype. The career data is sample data, and the percentage is not a professional assessment or a trained AI prediction.
